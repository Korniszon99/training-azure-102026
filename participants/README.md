# Uczestnicy

Dla każdego uczestnika utwórz katalog:

`participants/<github-login>/`

W środku powinien znaleźć się plik `README.md` utworzony na podstawie [szablonu wpisu uczestnika](../templates/PARTICIPANT.md).

Przykład:

```text
participants/
└── anna-kowalska/
    └── README.md
```

Wpis uczestnika powinien zawierać link do jego repozytorium oraz podstawowe informacje o wykonanym ćwiczeniu.

Nie kopiujemy tutaj całego repozytorium uczestnika.
