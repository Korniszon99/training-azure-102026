# Archiwum szkolenia

Ten katalog służy do zachowania końcowych artefaktów z ćwiczeń.

Dla każdego uczestnika można utworzyć katalog:

`archive/<github-login>/`

Może zawierać:

- `workflow.yml` — finalny workflow GitHub Actions napisany podczas szkolenia,
- `README.md` — krótki opis wdrożenia i użytej usługi Azure,
- dodatkowe niewrażliwe materiały pokazujące wynik ćwiczenia.

## Czego tu nie zapisujemy

Nie zapisujemy:

- sekretów GitHub Actions,
- client secretów,
- connection stringów,
- tokenów,
- publish profile,
- wartości z plików `.env`,
- danych osobowych niewymaganych do archiwizacji szkolenia.

Archiwum ma dokumentować rozwiązanie, nie dane dostępowe.
